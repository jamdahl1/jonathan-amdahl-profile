## Design idea

The private system keeps candidate truth separate from individual resumes.

```text
Candidate Truth
      +
Target
      ↓
Assessment
      ↓
Evidence-supported projection
      ↓
Resume / profile / study plan
```

This public repository contains only the intentionally published projection.
