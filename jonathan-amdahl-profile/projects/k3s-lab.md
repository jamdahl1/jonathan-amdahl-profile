# Raspberry Pi / K3s Lab

Independent infrastructure lab built around Raspberry Pi and K3s.

Areas explored include:

- Kubernetes/K3s cluster operation
- Helm
- Containerized workloads
- Offline-first ARM64 packaging
- Python wheelhouse deployment
- Shared-memory telemetry
- WebSocket and HTTP service boundaries
- Infrastructure consolidation
- Service discovery and cluster-oriented experimentation
