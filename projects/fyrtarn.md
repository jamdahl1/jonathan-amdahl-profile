# Fyrtarn

Independent systems-architecture work exploring explicit application boundaries,
capability contracts, compute surfaces, agent/application separation, dispatch preparation,
resource handling, and reusable infrastructure.

Areas explored include:

- Python application architecture
- Public semantic contracts
- Compute/capability boundaries
- Agent/application isolation
- Structured resource and data surfaces
- Worker/dispatch architecture
- Application portability
- Inspection and evidence of execution

The project is used as an engineering laboratory rather than presented as professional employment.
