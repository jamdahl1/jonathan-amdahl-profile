# Fyrtarn

## Independent systems architecture project

Fyrtarn is an engineering laboratory for explicit application boundaries, capability contracts, compute surfaces, agent/application separation, dispatch preparation, resource handling, and reusable infrastructure.

Its architecture separates a creation layer for authoring and validating graph-based artifacts, a trust layer for registration, versioning, policy, and placement, and an execution layer for running approved artifacts with status and provenance.

## Areas explored

- Python application architecture and public semantic contracts.
- Compute/capability boundaries and structured discovery.
- Agent/application isolation and worker/dispatch architecture.
- Ports and adapters that keep capabilities independent of transport and backend.
- Application portability, resource surfaces, and evidence of execution.

## Disclosure boundary

This project is used as an engineering laboratory rather than presented as professional employment. This public description omits private implementation details, credentials, deployment configuration, and unreleased system internals.
